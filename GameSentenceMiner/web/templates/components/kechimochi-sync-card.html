Kechimochi Sync

All history

Backfill from your first day in GSM, then keep your library, daily characters, and reading time up to date. Changes to past GSM activity are synced automatically, including deletions.

Open Kechimochi and turn on HTTP API in its profile tab. Both apps must be running to sync.

Saving with automatic sync enabled starts a full sync immediately. Missed runs catch up when GSM starts; connection failures retry within 15 minutes.

Cover images require Full scope in Kechimochi’s advanced HTTP API settings. Activity sync also works with Automation scope.

GSM also syncs descriptions, genres, tags, and source links. Supported sources such as VNDB, AniList, and Jiten provide a Refresh Metadata button in Kechimochi. Metadata added there is preserved until its GSM value changes.
