Exclusive fullscreen detected

OBS target

Exclusive fullscreen gives the game sole control of the display. When the GSM overlay or gamepad navigation takes focus, Windows may minimize the game, interrupting lookups and navigation.

Recommended: switch the game to Borderless Fullscreen or Windowed.

Check the game's Display or Graphics settings first. “Borderless,” “Fullscreen Windowed,” and “Windowed Fullscreen” are equivalent names. Alt + Enter also toggles window mode in many games.

If the game has no borderless option

Magpie

Best for older games that can run in a normal window.

A lightweight window scaler for Windows 10/11. Run the game in Windowed mode, then let Magpie present and upscale it fullscreen. It includes FSR, Anime4K, CRT filters, and multi-monitor support. GSM also recognizes Magpie and applies its compatibility behavior automatically.

Special K

Best when a game needs its window mode overridden.

A PC game mod framework that can force borderless fullscreen through Window Management. It also offers frame-pacing, limiter, HDR, and display controls. Compatibility varies by game; do not inject it into anti-cheat or online games unless the game explicitly permits it.

After changing the display mode, restore the game. GSM will stop warning once Windows no longer reports an exclusive Direct3D fullscreen session.
