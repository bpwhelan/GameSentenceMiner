                            Memory

                            Engine memory: —

                            Every installed dictionary is held in memory while the engine runs. Each dictionary's share is under its Details in Library. How Hachidori uses memory

                            Frees the memory an import or dictionary change leaves behind by restarting the engine once it is idle. Imports run on one thread and are slower, and dictionaries reload briefly after a change.

                            Low memory mode needs the threaded engine, which this browser does not run.

                            Experimental features

                            Experimental features may change or be removed in a later version. Turning one off hides it but keeps its settings for the next time you turn it on.
