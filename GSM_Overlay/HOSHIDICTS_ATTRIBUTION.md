# Hoshidicts Overlay Attribution

The Hoshidicts overlay integration contains or adapts GPL-licensed work from
the following projects:

- [Hoshidicts-rs](https://github.com/Manhhao/hoshidicts-rs), the safe Rust
  bindings for the Hoshidicts Yomitan-dictionary engine, consumed by
  `gsm_overlay_server` as a Git dependency pinned at the immutable commit
  [57a0e43](https://github.com/Manhhao/hoshidicts-rs/tree/57a0e434922a3192bc999f4971a9ca33c677c078).
  That commit's own recursive `hoshidicts` engine submodule points at
  [Manhhao/hoshidicts](https://github.com/Manhhao/hoshidicts) upstream at
  [8993838](https://github.com/Manhhao/hoshidicts/tree/899383893332a481d615ded3cab417a92ea4144f),
  which the crate builds and statically links, so GSM no longer vendors the
  engine or hand-writes the FFI glue. Both projects are licensed under
  GPL-3.0-or-later; the engine's complete license travels with the crate's
  bundled submodule.

  The pinned crate exposes the typed lookup-options API GSM consumes —
  `run_with_options` over `LookupOptions { frequency_dictionary,
  frequency_order, primary_reading }` and `LookupFrequencyOrder`, wrapping the
  engine's `hd_lookup_run_with_options`, which applies the caller's frequency
  and reading preferences before the result cap. GSM enforces its own
  consumer-side result and materialization caps on top of the upstream engine
  and does not depend on any fork-only engine guard.
- [Hoshi Reader](https://github.com/Manhhao/Hoshi-Reader/tree/c31c9d0ce376ff83bf6a91d908bf9f8e0fb4947b/Features/Popup),
  whose popup structure and furigana presentation informed
  `features/hoshidicts/reader.js`, `features/hoshidicts/popup.js`, and
  `features/hoshidicts/reader.css`. Hoshi Reader is licensed under
  GPL-3.0-or-later.
- [Yomitan GSM](https://github.com/bpwhelan/yomitan-gsm/tree/006dd464a50a468c71093dc8a8311f6110bf1996),
  the pinned source base for the bundled Yomitan extension and the dark popup
  palette adapted by `features/hoshidicts/reader.css`. Its Anki add,
  duplicate, and view icons are copied into `features/hoshidicts/icons`.
  Yomitan GSM is licensed under GPL-3.0-or-later.

The adapted reader sources, stylesheet, and copied icons carry
`SPDX-License-Identifier: GPL-3.0-or-later` headers. The repository's root
`LICENSE` contains the full GNU GPL version 3 text.

The optional dictionary installer links to, but does not redistribute, these
Yomitan-format dictionary releases:

- [Jitendex](https://jitendex.org), licensed under CC BY-SA 4.0 (with its
  example-sentence sources attributed in the archive);
- JMdict English (without proper names), JMnedict, and KANJIDIC from
  [yomidevs/jmdict-yomitan](https://github.com/yomidevs/jmdict-yomitan), whose
  project publishes the dictionaries under CC BY-SA 4.0 and whose archives
  include EDRDG attribution;
- BCCWJ and JPDB v2.2 frequency dictionaries from
  [Kuuuube/yomitan-dictionaries](https://github.com/Kuuuube/yomitan-dictionaries).
  That repository declares no license; its JPDB data is described as scraped,
  while NINJAL describes the BCCWJ source list as available for research and
  educational use;
- the frequency dictionary generated by [Jiten](https://jiten.moe). Jiten's
  software is Apache-2.0, but its generated dictionary archive states no
  separate data license; and
- [Kanjium Pitch Accents](https://github.com/toasted-nutbread/yomichan-pitch-accent-dictionary),
  derived from the CC BY-SA 4.0
  [Kanjium](https://github.com/mifunetoshiro/kanjium) data.

Archives carry varying source, license, and attribution metadata. Hoshidicts
preserves the metadata present in each index during import. BCCWJ, JPDB v2.2,
and the fixed 2020 Kanjium release do not provide update indexes, so scheduled
updates cannot update them automatically. JMdict remains an individually
installable alternative to Jitendex and is omitted from the one-click default
set to avoid duplicate definitions. Kanjium Pitch Accents is the sole
additional community suggestion in the one-click default set beyond Yomitan's
current upstream Japanese recommendations. The dynamically generated GSM
Character Dictionary from the bundled GSM catalog remains on Yomitan's existing
loopback-only sync path and is not fetched by Hoshidicts, whose remote
dictionary downloads remain HTTPS-only.
