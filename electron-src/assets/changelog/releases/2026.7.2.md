# What's Changed in 2026.7.2

This release adds an opt-in way to keep repeated Anki mines together. When GSM finds the same word in an older note of the same type, it can merge the new sentence, audio, screenshot, furigana, translation, and other configured context into that note using Kiku-compatible field grouping.

https://kiku.youyoumu.my.id/field-grouping.html

## Highlights

### 1. Kiku-Compatible Anki Field Grouping

- Enable **Field Grouping** in GSM's Anki settings to search for exact duplicate words while mining.
- Compatible context fields receive matching `data-group-id` markup so Kiku can keep each sentence, screenshot, and audio clip together.
- Existing group IDs are preserved, including cards that already contain several grouped contexts.
- Field grouping is off by default, so existing mining behavior does not change unless you enable it.

<!-- IMAGE SLOT 1: Field Grouping settings tab. Suggested asset: 2026.7.2/field-grouping-settings.png -->

### 2. Choose What Gets Merged

- Every duplicate match opens a decision dialog before GSM merges anything.
- If several matching notes exist, choose which original note should receive the new context.
- Choose whether the new context appears first or last, whether the newly created duplicate is deleted after a successful merge, or keep the notes completely separate.
- GSM updates the original before deleting the duplicate, so a failed update does not discard the newly mined note.

<!-- IMAGE SLOT 2: Duplicate-note merge dialog. Suggested asset: 2026.7.2/field-grouping-dialog.png -->

### 3. Configurable Grouped Fields

- Picture, sentence, sentence audio, sentence furigana, and configured AI translation fields are handled automatically.
- Add any other text fields that should stay aligned with the grouped context.
- Tags from the new note are carried onto the original while Anki's special `leech`, `marked`, and `potential_leech` tags are left alone.

## Detailed Changelog

### Anki and Card Creation

- Added exact duplicate-word discovery within the same Anki note type.
- Added Kiku-compatible grouping for text and image fields while preserving existing HTML and `data-group-id` values.
- Added front/back placement for newly grouped context.
- Added safe merging into a selected original note, optional duplicate deletion, tag transfer, and overlay-tag cleanup.
- Continued the normal card pipeline when no match is found, grouping is disabled, or the user keeps the new note separate.

### Settings and Interface

- Added an Anki **Field Grouping** settings page with opt-in enablement, default ordering, duplicate-deletion preference, additional grouped fields, and a link to Kiku's field-grouping documentation.
- Added a duplicate-note dialog that previews matching notes by sentence and tags.
- Stored field-grouping preferences per profile and normalized older or invalid configuration values safely.

### Tests and Maintenance

- Added regression coverage for duplicate discovery, grouping order, existing group IDs, image grouping, tag handling, successful merge/deletion order, configuration defaults, and the Qt decision dialog.
- Removed a fragile stats-dashboard test that depended on timing-sensitive browser behavior.
