# What's Changed in 2026.9.5

This release improves overlay navigation, game detection, and update diagnostics.

---

## Overlay

### Fix controller and keyboard navigation

Fixed missed or repeated inputs, unwanted selection resets, and delayed dictionary results selecting an old line. Navigation handles wrapped text and nested dictionary popups more consistently. Manual activation waits for selectable text before opening a lookup; releasing activation cancels a pending lookup.

### Disable DInput by default on Windows

Extended controller support is opt-in **for now**. For native Switch, PlayStation, or generic DirectInput controllers, enable **Overlay Settings → Gamepad → Input Server Settings → Enable Extended Controller Support (DirectInput / SDL)**. Restart GSM after changing either listener. Turn both listeners off to disable controller input throughout GSM while keeping keyboard navigation available. I wasn't 100% confident issues people were having was because of this, but i think it's better for people to know what they are enabling and allow our tried and true implementation remain as default for now.

![Controller listener settings with XInput enabled and extended controller support disabled](2026.9.5/controller-listeners.png)

### Open and close the overlay with the active game

Enable **Home → Overlay → Open and close with active game** to start the overlay when a game session is detected and close it when the session ends. This is off by default and replaces **Run on startup** when enabled. On Windows, alt-tabbing or minimizing a tracked game does not end its session.

![The Overlay card showing Open and close with active game and Run on startup](2026.9.5/overlay-automation.avif)

### Reject stale capture targets

Manual capture and navigation reject invalid targets, preventing stale captures after the game closes.

### Adjust capture timing after text hooks

Hook-triggered OCR learns a small initial delay when dialogue repeatedly appears after the hook fires.

---

## Updates

### Read release notes before installing

An in-app update notice opens the release notes before you choose to install.

### Save installation and update diagnostics

Installation stages, retries, updater errors, and dependency output now survive in GSM's normal logs and **Export Logs**, including failures before the backend starts.

---

## Other improvements

- **Agent scripts: preserve custom files during updates.** Managed script updates preserve your custom files and local edits.
- **Statistics: use adaptive reading-time calculations.** The fixed calculation option was removed, so previously fixed-mode totals may change.
- **Audio: fix cut-and-splice failures and trimmed-audio fades.** Fixed failures when combining audio segments. Fades now start at the beginning of the trimmed audio instead of the original file.
- **Text Feed: follow growing speech transcripts.** Automatic scrolling now follows revisions to the newest line.
- **Text Feed: load custom CSS from a URL.** Settings now accept a URL for custom CSS.
- **Tadoku: edit log titles before uploading.** The manual sync preview lets you edit each game's log title.
- **AI: match Gemini thinking settings to the model.** Fixed unsupported thinking options being sent to Gemini models.
- **AI: try backup models sooner.** Reduced retries for temporary errors before trying the configured backup model.
- **Linux: pause the game configured in the active OBS scene.** When no hook is attached, process pausing uses the scene's **Game executable**.
- **Fixed a monitor placement bug in the Overlay.**
