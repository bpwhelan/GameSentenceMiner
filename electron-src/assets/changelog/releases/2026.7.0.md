# What's Changed in 2026.7.0

This release is mostly about making GSM easier to control while you are playing. OCR has fewer setup traps, overlay settings are easier to find, stats open to more useful date ranges, text sources step on each other less often, and more flexibility around the Anki Confirmation Dialogue.

I'm not sure if I like these notes since they are quite wordy, but a lot of the changes are not too obvious, so I wanted to give a bit more context.

## Highlights

### 1. In-App Changelog

The desktop app now has a "What's Changed" dialog for updates, which you should be seeing now. :D

### 2. Overlay

#### Periodic Scanning

Periodic Scanning was moved to legacy a while ago, but has since gone through some important changes that may make it more viable.

- Added option to only do the periodic scans when the mouse is moving (Windows Only). Inspired by [Meikipop](https://github.com/rtr46/meikipop). This will reduce the number of scans when you are AFK, and may help with performance in some games. This could also be useful for supplementing OCR in games that have text that is not always visible, like VN Choices.
- If no texthook/ocr matches are found, GSM can fall back to text found via the periodic scan during card creation. This should make it possible to ONLY run the overlay with periodic scans, but I definitely don't recommend it for many reasons. Stats, Reliability, timing, and I haven't tested it enough to know if it works well. But it should work in theory.

#### Other

Overlay settings have been reorganized so they are easier to browse and search. I THINK I MIGHT CHANGE THIS AGAIN SOON IN THE FUTURE, I'm still not really satisfied with the organization, and I'm not even sure if it's better than it was.

- Overlay settings now have local search across the overlay settings UI.
- Settings are grouped into clearer categories, including overview, reading, interaction, gamepad, stats/goals, and dictionary areas.
- The new Overlay Overview tab gives common overlay features a more obvious home and links directly to the relevant settings.
- Overlay Capture Settings now live inside the overlay settings area instead of being split across separate settings pages.
- Gamepad overlay visibility has new settings, so gamepad users have more control over when overlay UI appears.
- Overlay behavior is more aware of the active foreground window on Windows.
- Added hotkey to hide overlay stats and goals, press multiple times to change view.
- Jiten Reader has been updated to the latest version, which may or may not be useful for GSM? Time will tell.

### 3. OCR


- The old OCR port setting has been removed. GSM now manages that connection internally.
- Area Selector changes can update the running OCR session, which means you can keep the selector box and change capture boxes on the fly.
- The Area Selector itself is cleaner, with no separate floating control box. Hiding info will now be remembered across sessions.
- Overlapping or stacked OCR boxes are easier to remove reliably.
- New Option in Advanced ONLY for multi-box setups. Compact selected text areas before recognition. This can make OCR faster for games with several separate text boxes spread across the screen. May cause issues with some checks such as menu detection or black-hole boxes, but seems to work fine.

### 4. Stats

Stats pages should start from a more useful date range, especially if you have imported history or data from other sources.

- GSM now checks both combined rollup data and third-party/imported data when choosing the first available stats date.
- Imported history is less likely to be hidden behind a too-recent default range.
- Kanji-based Anki stats have a fallback path, so kanji stats and filters are less likely to appear empty when one extraction path is incomplete. Thank you [@bee](https://github.com/bee-san)
- Reading-time and live-stats behavior has been tightened up around newer text source handling.
- Game-linking labels in database, import, overview, game stats, and search screens have been clarified.
- Added "Last Month" "Last Week", and "Last Year" in quick-select dates.

---

### 5. Text Intake

GSM now does a better job of understanding where incoming text is coming from.

- Clipboard polling can pause while GSM is already receiving text from OCR or an in-house text hook.
- The desktop app can warn when Auto OCR and a text hook are running at the same time. This is a common source of confusion where users believe that OCR in the OCR tab is required for Overlay.
- Text preview events are forwarded from the backend to Electron more consistently.
- Text hook status reporting from Electron back to the backend has been improved.

![OCR duplicate source warning](2026.7.0/ocr_dupe_warning.png)

---

### 6. Anki Cancellation

Cancelling the Anki confirmation flow should leave less cleanup behind.

- If GSM creates a note for confirmation and you cancel the flow, GSM can delete that newly created note when appropriate.
- This helps avoid stray cards from abandoned captures.
- The cleanup path is covered by new tests.
