# What's Changed in 2026.10.3

Faster local OCR, cleaner reading stats, and easier OBS updates.

## VOCR: faster and ready offline

VOCR now uses **ONNX on CPU**. All three model sizes and the text detector ship with GSM, so there's no separate VOCR download on first use. Your existing OCR engine choice and VOCR model size are preserved.

Whole-image OCR on a Ryzen 7 5800X, using one CPU thread:

| Model | Previous C (ms) | Bundled ONNX (ms) | Speedup |
| --- | ---: | ---: | ---: |
| Small | 76.03 | 34.17 | **2.23×** |
| Normal | 82.07 | 40.89 | **2.01×** |
| Large | 145.45 | 51.38 | **2.83×** |

Milliseconds per image, including detection and recognition; lower is better. This is a small, 12-image local comparison. Actual gameplay performance varies.

Choose **OCR → Advanced → Recognition → Main OCR → VOCR**; overlay OCR uses the same model selection. The bundled models add about 17 MB before compression and retain their non-commercial-use restriction.

## Fast-forward without inflated reading stats

Detected skip bursts are excluded from reading stats while text history and manual mining remain available. Normal automatic text has a short delay before it counts.

The overlay pauses automatic scans during fast-forward and scans the current screen when text settles, so dialogue and choices become available for lookup without needing another line to arrive.

## Update and restore OBS from GSM

On Windows, **Settings → Updates → OBS Studio** can update GSM's portable OBS while preserving scenes, settings, and plugins. Replay buffering resumes afterward, and **Restore OBS** returns to the previous installation and its configuration.

Automatic updates are **off by default**. Recording or streaming blocks an update; custom and remote OBS installations are left alone.

## Fixes

- Toggling the overlay off closes Hachidori and Yomitan lookups, including nested popups and pending lookups.
