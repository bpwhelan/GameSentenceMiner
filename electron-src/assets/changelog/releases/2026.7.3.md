# What's Changed in 2026.7.3

This release makes data-folder changes non-destructive, improves OCR setup and Windows stability OCR defaults, and makes automatic overlay visibility more reliable for games and OBS sources without native windows. It also adds automatic and overwrite modes for Anki field grouping, preserves formatted target text during translation prefetch, compacts the Anki sync cache, and lets the Today stats card roll over at a chosen hour.

## Highlights


### 1. MeikiTextDetector as Default Stability Engine for OCR

- Basic OCR on Windows now uses Meiki Text Detector for the stability pass instead of OneOCR. This comes with better speed, less memory usage, and more consistent results. This is subject to change back to OneOCR or ScreenAI if users are negatively impacted.

### 2. More Reliable Automatic Overlay Visibility

Walked back some of the changes I made to hide the overlay on startup to wait for active game capture. This is now opt-in, and nonconventional capture types are re-supported.

- Capture-card, camera, and other OBS scenes without a native game window can now reveal the overlay when OBS confirms visible output.
- Startup and recovery behavior now distinguishes active output from obscured, minimized, closed, and empty scenes so the overlay is less likely to flash, remain hidden, or stop unnecessarily.
- Better Config Sync
- Got Rid of overlay closing from Game Automation's "Open Overlay Automatically". It will now open automatically but not close automatically.


### 3. Duplicate Merge Updates, Automatic Merge, Overwrite

- **Merge Automatically** can merge a new mine into the oldest exact match using the configured order and duplicate-deletion defaults without opening the decision dialog.
- **Overwrite Instead of Merge** replaces grouped fields with non-empty values from the new mine instead of adding Kiku `data-group-id` markup. This is useful when a newer voiced context should replace an older context or when the note type does not support Kiku-style merging. Thank you [@Musi57](https://github.com/Musi57)
- Automatic merging and overwrite mode are both off by default. The existing review dialog and Kiku-compatible merge behavior remain unchanged until the new options are enabled.
- Empty values in the new note do not blank the original, and grouped fields remain aligned when one side has no content.

### 4. Portable AppData Folder

This is lightly tested, and there are probably tons of pitfalls that i haven't been able to find. Only use out of necessity.

- The desktop Settings page now shows the active data folder and provides a guided way to choose a new location.
- GSM copies its database, core configuration, desktop settings, overlay settings, and supported OBS configuration, then switches to the new location only after the copy succeeds.
- Source files are never deleted, and GSM refuses to overwrite an existing destination file.
- Chromium session/storage, Yomitan data, caches, logs, installed tools, and other runtime data are intentionally not copied. Export Yomitan dictionaries before changing folders and import them afterward.
- When a custom data folder is active, **Use Original AppData Folder** switches back to the data already present there. It does not copy newer changes back, and it leaves the custom folder untouched.


### 4. Text Capture Wizard Changes

- The Text Capture Wizard now runs one OCR scan after an area is selected and previews the captured text immediately.
- Retry the scan from the wizard if no text is detected or the dialogue was not visible during the first scan.
- Save whether each OBS scene should leave OCR off, start Manual OCR, or start Auto OCR when that game starts.
- Agent/Texthook Tabs will now properly save Hooks.

### 5. Configurable Today Stats Rollover

Thank you [@bee](https://github.com/bee-san)

- Choose an hour from 0 through 23 when the Overview **Today** card starts a new day.
- The default remains 4 AM. Activity before the chosen hour counts toward the previous day.
- This setting changes only the Today card's time window; other daily statistics and streak calculations are unchanged.

## Detailed Changelog

### Data, Recovery, and OBS

- Added localized data-folder controls, progress reporting, restart handling, and a restore-to-AppData action to the Electron Settings page.
- Retargeted managed portable OBS paths after copying while preserving custom OBS paths.
- Excluded Chromium storage, Yomitan dictionaries, OBS startup markers, runtime locks, logs, caches, Python environments, and installed tools from relocation.
- Removed stale OBS startup artifacts beside the configured portable OBS executable and rechecked cached managed-process state before treating OBS as already running.

### OCR and Text Capture

- Centralized platform-specific Basic OCR defaults across Electron and Python.
- Added initial OCR startup, result, timeout, retry, and error handling to the Text Capture Wizard.
- Saved scene-scoped OCR automation alongside Agent and Luna text-hook profile settings.
- Added stability-OCR benchmarking and report tooling for maintainers.

### Overlay and Profiles

- Added output-aware visibility decisions for scenes that cannot be associated with a native window handle.
- Restored the automatic overlay when OBS output returns after an empty scene and avoided hiding an already-running overlay during transient scene checks.
- Sent the authoritative profile name and scene list to the overlay on connect, save, and request.
- Added a guarded, currently disabled in-process overlay runtime with lifecycle coverage; production builds continue to use the existing separate overlay process.

### Anki and Card Creation

- Added optional automatic field grouping into the oldest exact note match.
- Added all-fields overwrite mode while protecting original values from empty replacements.
- Preserved target-word HTML in the early AI translation prefetch for first-card, single-line, and selected multi-line mining paths.
- Reduced Anki cache storage to the configured word field value GSM reads. A full sync rewrites existing note rows into the compact shape.

### Statistics

- Added `day_rollover_hour` to the profile configuration, settings API, validation, statistics modal, and Overview Today query.
- Covered custom rollover hours, midnight rollover, invalid values, default migration, and persistence.

### Tests and Maintenance

- Added regression coverage for data relocation conflicts and copy boundaries, managed OBS path retargeting, OCR wizard sampling and automation, overlay visibility, profile synchronization, field grouping, Anki cache shape, and Today rollover behavior.
- Made lazy-import subprocess probes resilient to asynchronous shutdown logs so platform log ordering cannot corrupt their JSON result.
- Expanded English, Japanese, and Ukrainian localization for the new Electron settings and wizard flows.
- Added implementation documentation for Anki field grouping.
