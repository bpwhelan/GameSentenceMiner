# What's Changed in 2026.11.0

This release adds a way to review cards after playing and launch games from GSM.

## Review cards after your session

You can now leave confirmation until you've finished playing. Cards still go to Anki as you mine; when the game closes, GSM opens a review queue where you can adjust dialogue, audio, screenshots, and translations together. Pending reviews survive restarts, and **Review pending cards now** lets you return to them earlier.

This is **off by default**. Use the button below to enable it for your current profile, or open **Anki → Confirmation** in GSM settings, turn on **Enabled**, and select **After session**. Choose **As soon as possible** to return to confirmation during play. Saved replay copies use disk space until reviewed.

[Enable after-session review](https://gsm-setting.invalid/review-after-session/enable)

![The after-session review queue with dialogue, audio, and screenshot controls](2026.11.0/session-review.png)

## Launch games from Home

On **Windows**, select a game on Home and choose **Launch game**. GSM remembers its executable when it can detect it; otherwise, set it in **Launch options**. You can also save arguments, a working folder, and an installed custom launcher such as Locale Emulator or Special K.

![Home showing Launch game and Launch options for the selected game](2026.11.0/game-launch.png)

## Text feed

The text feed has a more modern layout. You can still mine multiple lines by clicking on each line or clicking and dragging.

![The redesigned text feed with translations and two lines selected for mining](2026.11.0/text-feed.png)

## Other changes

- More compact settings and immediate confirmation windows, with grouped previews and audio editing controls.
- Separate OCR engine choices for menu and area selections.
- FireRed is the default voice detector again. Older profiles using Silero or no detector switch once; you can change it back afterward.
- Automatic repair after a failed backend setup, and restored **Command-Q** on macOS.
- A `--profile "filepath/to/profile"` CLI option to force GSM to save all config and data to a specific folder, useful for completely seperating different languages or for testing new setups.

## Looking ahead

This may be one of the last releases before some longer-term changes to GSM's identity... Planning on shrinking GSM to be a more streamlined experience, while still keeping much of the power-user features.
