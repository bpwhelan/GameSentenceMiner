# What's Changed in 2026.10.0

Text hooking is easier to set up, inspect, and keep up to date.

## Highlights

### A clearer Texthook / Agent tab

Follow the flow from choosing an engine to selecting a hook, checking its output, and saving it for next time. Capture options, help, and engine diagnostics are tucked into expandable sections.

![The updated Texthook / Agent tab with detected hooks, selected output, and Save for next time](2026.10.0/text-hook-tab.jpg)

*Shown with sample hooks.*

### Find useful hooks more easily

Luna and Textractor now put readable text and likely matches for your target language first. Likely noise is hidden until you enable **Show likely noise**; your selected hook stays visible. Language hints are approximate. Repeated redraws of the same selected text no longer flood GSM's text feed.

### Updated LunaHook, with easier future updates

LunaHook is updated to **10.17.1.12**. I've also streamlined the build and update process, so it'll be much easier for me to keep GSM's LunaHook build up to date.

Text-hook engine updates are **automatic by default**, separate from GSM app updates. They download in the background and wait for text capture to stop before switching. For manual checks, repair, or disabling automatic updates, open **Texthook / Agent → Troubleshooting**.

## Other improvements

- Hide overlay text when it's covered by other windows on Windows. (For anyone worried, this should add 0 extra CPU work, we are already checking window layout periodically, this just goes overtop of that)
- Catch Spammed Duplicate Text in Texthook tab before it gets sent anywhere.
- Update Hachidori to 0.2.2
- Choose English, original, or romaji game titles for Tadoku uploads.
- Fix reading-time estimates and session resets caused by Discord presence stopping.
- Preserve UTF-8 text split across process output chunks and detect Eden launches promptly.
- Detect Yuzu/Eden/Ryujinx(?) launch earlier so agent can inject before the game loads. This allows for using special shortcuts to launch Emulated Games.
- Fix Restore game focus after certain navigation conditions.
- Fix OBS capture target selection, replay-buffer startup, and unavailable recording/output folders (path issues.)
