# What's Changed in 2026.9.4

A small update to fix dictionary lookups and popup navigation in the overlay.

- Fixed Yomitan lookups failing after an update, including updates that reuse the same extension version. Your imported dictionaries are preserved.
- Fixed repeated Hachidori navigation inputs hiding a lookup or restarting it while results are loading. (Gamepad Lag)
- Closing a nested dictionary popup now keeps the selected action in the parent popup.
