# Text Feed translation and analysis

On Windows, the release desktop served a cached translation in 0.59 ms. The existing Flask route took 7.97 ms to fetch the same result through the desktop bus. The provider used for cache misses was a loopback OpenAI-compatible fixture. An external model would add its own inference and network latency.

| Text Feed operation | Flask wall ms | Rust wall ms | Flask CPU ms | Rust CPU ms | Flask + desktop private MiB | Rust desktop private MiB |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Refresh a live line | 8.71 | 1.36 | 9.28 | 0.49 | 81.96 | 9.14 |
| Read its cached translation | 7.97 | 0.59 | 8.79 | <0.49¹ | 81.91 | 9.14 |
| Translate multiple lines | 9.79 | 1.36 | 8.79 | 0.49 | 81.95 | 9.14 |
| Explain a sentence | 9.15 | 1.33 | 9.28 | 0.98 | 81.95 | 9.15 |
| Translate a saved line | 7.93 | 1.73 | 8.30 | 0.49 | 81.81 | 9.15 |

Each figure is the median of five batches of 32 requests. The fixture fed 128 dialogue lines through a WebSocket and used the same desktop, profile, model endpoint and three-line context setting in both modes. The Flask measurement includes Waitress, its Python interpreter and the desktop it calls. Memory is the sum of unique working sets sampled after each batch. The driver and mock provider are excluded from CPU and memory totals.

¹ The median cached batch registered zero CPU ticks. One 15.625 ms Windows CPU tick across 32 requests is about 0.49 ms per request.

The fixture compares full prompts and returned hashes, including the profile language, selected text, context order and saved scene. It also checks custom prompts, the setup response, quota-error redaction and the question length limit. Four simultaneous translations of the same edited line resulted in one provider call.

Run `.venv/Scripts/python.exe scripts/benchmark_reader_ai.py` from the repository root after building the release desktop. [Raw samples and executable digest](reader-ai-2026-11-21.json)

## Overlay WebSocket

| Overlay operation | Python wall ms | Rust wall ms | Python CPU ms | Rust CPU ms | Python + desktop private MiB | Rust desktop private MiB |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Translate two blocks | 8.34 | 0.97 | 9.77 | 0.49 | 88.46 | 8.97 |
| Analyze a sentence | 8.38 | 0.97 | 10.25 | 0.49 | 88.19 | 9.03 |
| Read cached flat text | 7.92 | 0.38 | 10.25 | 0.49 | 88.79 | 9.04 |

Five rounds of 32 messages used the public overlay socket, the same local provider and matching dialogue context. The harness compared the prompts received by the provider, block ordering, request IDs and broadcasts. Two connected overlays received a single provider response. A burst of changing screens translated only the active screen and the latest waiting screen. Run the same harness with `--overlay`. [Raw samples and executable digest](overlay-ai-2026-11-21.json)
