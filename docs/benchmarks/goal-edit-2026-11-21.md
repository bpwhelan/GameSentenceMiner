# Custom reading goal edits

Saving 100 timed goals took 0.84 ms in the release Rust handler and 2.38 ms through the Flask application. Both stored the same goals, settings and versions. The Rust writer validates goal windows before opening its transaction and reads the old settings only when a request needs to merge them. Concurrent edits to separate nested keys survive the merge.

| Edit | Flask wall ms | Rust wall ms | Flask CPU ms | Rust CPU ms | Flask peak working set MiB | Rust peak working set MiB |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Replace 100 timed goals | 2.38 | 0.84 | 1.95 | 0.78 | 68.66 | 7.01 |
| Replace settings | 1.24 | 0.58 | 1.17 | <0.39¹ | 68.73 | 7.01 |
| Merge two nested settings | 1.22 | 0.51 | 0.78 | <0.39¹ | 68.77 | 7.01 |

Five rounds alternated worker order. Each round measured 40 requests, including JSON parsing, validation, SQLite commit and response serialization. Both workers had an independent copy of the same WAL-mode SQLite fixture. The time excludes HTTP transport. Peak working set includes the entire benchmark worker. A desktop HTTP integration test separately exercises saving and reading goals with its Python upstream absent.

¹ These median batches registered zero CPU ticks. A single 15.625 ms Windows CPU tick across 40 requests is about 0.39 ms per request.

Reproduce with `cargo build --release --locked --manifest-path native/gsm-web/Cargo.toml --example report_benchmark` and `.venv/Scripts/python.exe scripts/benchmark_stats_web.py --goal-edits`. [Raw samples](goal-edit-2026-11-21.json)

## Reading pace

The 30-day reading pace query took 1.43 ms through Flask and 0.14 ms in release Rust. The fixture contained 50,000 historical lines, 365 daily rollups and 20 live lines. The two handlers returned the same values. Median worker CPU per request was 1.56 ms for Python and below the 0.39 ms tick resolution for Rust. Peak working sets were 75.38 and 8.66 MiB respectively. Run the same harness with `--only /api/goals/reading-pace`. [Raw samples](goal-pace-2026-11-21.json)
